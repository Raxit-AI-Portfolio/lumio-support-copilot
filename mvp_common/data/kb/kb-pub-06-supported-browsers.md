Lumio runs in the browser and also has a mobile app. This page lists what is supported.

## Desktop browsers

Lumio supports the latest two major versions of Chrome, Firefox, Edge and Safari. Older versions may work but we do not fix problems found only in them. Internet Explorer is not supported.

## Mobile app

The mobile app runs on the last three major versions of the two big phone systems. The app needs an internet connection to sync but lets you read cards you opened recently while offline.

## Settings that must be on

JavaScript and cookies must be enabled for the Lumio site. Some browser extensions that block scripts can stop the board from loading. If a board stays blank, try a private window with extensions off.

## Screen size

Boards work best on screens at least 1024 pixels wide. On smaller screens Lumio shows a simpler list view.
